# issue 211 — 提示词必须由插件自带,不能依赖全局 AGENTS.md

grade: standard

## 用户诉求(原话)

> 我需要所有的提示词注入等,都是包含在插件内,而不是在全局的 agents.md 里面,因为这样做意味着插件在别的设备上安装,就完全失效了。

## 问题(实测)

### 1. 两份拷贝

`~/.dsh/AGENTS.md` 的「工作方式:速度与质量优先」整段与 `dsh-task-dispatcher` 注入的段落是**同一份内容的两份拷贝**。
实测比对(`renderDelegationText('zh')` 2196 字符 vs 全局 2958 字符):

| 短语 | 插件注入 | 全局文件 |
|---|---|---|
| 开工第一件事 | ✓ | |
| 三问 | ✓ | **✓ 重复** |
| 可数条件就必须拆 / 停手重新拆解 / 堵掉逃生口 / 扇出不改变授权 | ✓ | |
| 检索纪律 · 零命中 · 易失路径 | | ✓ **只在这里** |

### 2. 只存在于全局的部分(#211 前)

用 `renderDelegationText('zh')` 逐条探测,以下条款**任何插件都没有**:

| 条款 | 状态 |
|---|---|
| 检索纪律(零命中 ≠ 不存在 / 双源交叉 / 易失路径先落盘) | MISS |
| 质量红线(汇总核对冲突重复遗漏 / 未验证标注 / 委派失败兜底) | MISS |
| 效率细则(先读后写 / 独立调用并发) | MISS |

即:换台机器装上插件,这三类规则**一条都不会有**。

### 3. 漂移已经发生

全局那份还写着「按任务内容选 `agent_preset`」「`/plan`」「`refactor-clean`」,
而插件那份已按 #207 全部改对。同一套规则两个真源,必然有一个先烂。

## 目标

1. 插件自带它依赖的**全部**提示词:三问、分档、硬触发、反逃生口、质量红线、检索纪律、效率细则、危险操作、角色表。
2. 注入文本**不引用**任何机器本地路径(`AGENTS.md`、`~/.dsh`)。
3. 契约测试逐条钉住(删即红),防止将来又漂回全局。
4. 给出一份「新设备安装后应得到什么」的核对清单。

## 边界

- 不改 133 行 preset、不改 DSH 运行时。
- **不删**全局 `~/.dsh/AGENTS.md` 的内容(那是用户文件);清单里给出建议,由用户决定。
- 规则库 bootstrap(`~/.agents/rules-library/`)是部署本地约定,**不**搬进插件。
- 测试与示例不得依赖仓库外文件(CI 无 `~/.dsh`;依赖即「只在我机器上能用」)。

## 验收

| # | 判据 | 证据 |
|---|---|---|
| A1 | 每条应自带条款都出现在注入文本(zh) | `test/owned-clauses.test.mjs` |
| A2 | en 渲染同样齐全 | 同上 |
| A3 | 注入文本不出现 `AGENTS.md` / `~/.dsh` | 同上 |
| A4 | 在隔离 HOME 下全绿(模拟干净机器) | `env HOME=/tmp/fakehome node --test test/*.test.mjs` |
| A5 | 安装清单可执行、命令实测通过 | `docs/prompt-injection-inventory.md` |

## 实测结果

- 补进注入段(zh/en 同构):质量红线 4 条、检索纪律 3 条、效率细则 3 条。
- 新增 `test/owned-clauses.test.mjs` 3 条契约。
- 新增 `docs/prompt-injection-inventory.md`(含可复制自检命令,已实测)。
- `pnpm test`:**1523 条 0 红**;`pnpm verify` exit 0;隔离 HOME 下 dispatcher 84/84 全绿。

## 反向验证(实测)

- 删掉「检索纪律」bullet → A1 + A2 红;还原后全绿。
- 注入文本写入 `~/.dsh` → A3 红(由 `doesNotMatch` 守护)。
