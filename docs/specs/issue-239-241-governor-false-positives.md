# issue-239/240/241:三处误判合法文本

**分级:standard**(一个包、三个检测器,都会静默改写/截断模型正文)

## 目标

1. **#239 数字失控必须落在文本尾部**:`detectNumberRunaway` 旧实现在第一个合格 run 处 return,中段合法列表(种子数组、端口表)被当失控,`trimTo` 落回列表开头,其后正文全被截掉。
2. **#240 裸 `tool_call` 块要看块内内容**:强模式只要求成对标签,文档示例即触发伪调用软切,并归因「你的调用没被执行」;围栏从未参与判定。
3. **#241 撇号不得吞掉句号**:`maskQuotedSentenceStops` 把英文撇号当引号开合,奇数个单引号后整段思考塌成一句,锚点把铺垫当结论、软切闸被拒。

## 边界

- 只改 `packages/dsh-deep-ptc-mode` 的 `lib/governor-softcut.mjs`、`lib/governor-anchor.mjs` 与 `lib/governor-apply.mjs` 的一处调用,外加新增测试;不动设置项与其它检测器。
- 不降低真阳性:裸块带名字信号仍命中、尾部计数流仍命中、成对引号仍按引号处理。

## 变更点

1. **#239 的尾向判据改成「run 之后不再出现字母/汉字」而不是「距文末 400 字内」**​:后者会把「列表 + 两句结论」也放过,前者与直观语义一致——模型一旦恢复成句就说明它停了。
2. **#240 的围栏豁免放在 `hasPseudoToolCall` 内部**(剔除闭合围栏 + 剔除未闭合围栏及其后内容),而不是在 `governor-apply.mjs` 调用点再加一次 `insideUnclosedCodeFence` 判断:一处实现,两种围栏形态都覆盖,调用点保持薄。
3. **#241 的落单引号按字面处理**:除了撇号规则,还要求开引号时后面确实还有同种引号可配对;奇数引号不再把后续句号全部掩掉。
